# Système d'Optimisation - Affectation de Techniciens de Maintenance

Projet de Recherche Opérationnelle (INSAT)  
Modèle PLNE avec Gurobi pour l'affectation optimale de techniciens à des pannes de maintenance.

## Structure
- `main.py` : lancement de l'application
- `solver.py` : modèle d'optimisation et thread
- `interface.py` : interface graphique complète (PySide6 + Matplotlib)

## Dépendances
- gurobipy
- PySide6
- matplotlib
- numpy

Licence Gurobi académique requise.
