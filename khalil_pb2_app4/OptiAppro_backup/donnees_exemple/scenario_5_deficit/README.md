# Scénario 5 : Déficit d'offre (4 sites, 2 matières)

## Règle fondamentale respectée
**Un site qui OFFRE une matière ne la DEMANDE PAS**

## Sites
| Site | Offre | Demande |
|------|-------|---------|
| Centre_1 | 80t Produit_A | 50t Produit_B |
| Centre_2 | 60t Produit_B | 60t Produit_A |
| Centre_3 | 40t Produit_A + 30t Produit_B | Rien |
| Centre_4 | Rien | 100t Produit_A + 80t Produit_B |

## Particularité : DÉFICIT
- **Produit_A** : Offre=120t, Demande=160t → **Déficit 40t**
- **Produit_B** : Offre=90t, Demande=130t → **Déficit 40t**

Ce scénario illustre les **ruptures** quand l'offre < demande.
