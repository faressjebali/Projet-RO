# Scénario 3 : Capacités limitées (4 sites, 3 matières)

## Règle fondamentale respectée
**Un site qui OFFRE une matière ne la DEMANDE PAS**

## Sites
| Site | Offre | Demande |
|------|-------|---------|
| Depot_A | 120t Fer | 80t Cuivre + 40t Zinc |
| Depot_B | 150t Cuivre | 60t Fer + 50t Zinc |
| Depot_C | 100t Zinc | 70t Fer + 60t Cuivre |
| Depot_D | 80t Fer + 50t Cuivre + 50t Zinc | Rien |

## Particularité
**Capacités de transfert limitées à 40 tonnes par arc !**

## Équilibre
- Fer : Offre=200t, Demande=130t → Surplus
- Cuivre : Offre=200t, Demande=140t → Surplus
- Zinc : Offre=150t, Demande=90t → Surplus

## Coûts : 2.5 à 6 DT/tonne
