# Scénario 1 : Simple (3 sites, 2 matières)

## Règle fondamentale respectée
**Un site qui OFFRE une matière ne la DEMANDE PAS (et vice versa)**

## Sites
| Site | Rôle | Offre | Demande |
|------|------|-------|---------|
| Usine_Nord | Producteur Acier | 150t Acier | 60t Plastique |
| Usine_Sud | Producteur Plastique | 120t Plastique | 80t Acier |
| Usine_Centre | Consommateur | Rien | 70t Acier + 60t Plastique |

## Équilibre
- **Acier** : Offre=150t, Demande=150t → Équilibré parfait
- **Plastique** : Offre=120t, Demande=120t → Équilibré parfait

## Coûts
- Transport : 2.5 à 5 DT/tonne
- Distance max : 150 km
