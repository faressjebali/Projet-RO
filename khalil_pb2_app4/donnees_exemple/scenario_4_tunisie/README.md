# Scénario 4 : Villes tunisiennes (5 sites, 3 matières)

## Règle fondamentale respectée
**Un site qui OFFRE une matière ne la DEMANDE PAS**

## Sites
| Ville | Rôle | Offre | Demande |
|-------|------|-------|---------|
| Tunis | Consommateur | Rien | 80t Bois + 120t Métal + 100t Textile |
| Sfax | Producteur Métal | 200t Métal | 50t Bois + 60t Textile |
| Sousse | Producteur Bois | 100t Bois | 80t Métal + 70t Textile |
| Bizerte | Producteur Textile | 150t Textile | 50t Bois + 100t Métal |
| Gabès | Producteur mixte | 80t Bois + 100t Métal + 80t Textile | Rien |

## Distances réelles (km)
- Tunis-Bizerte: 65km
- Tunis-Sousse: 140km
- Sfax-Gabès: 150km

## Équilibre
- Bois : Offre=180t, Demande=180t → Équilibré
- Métal : Offre=300t, Demande=300t → Équilibré
- Textile : Offre=230t, Demande=230t → Équilibré

## Coûts : 1.5 à 13 DT/tonne
