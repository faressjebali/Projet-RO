# Scénario 2 : Surplus d'offre (4 sites, 2 matières)

## Règle fondamentale respectée
**Un site qui OFFRE une matière ne la DEMANDE PAS**

## Sites
| Site | Rôle | Offre | Demande |
|------|------|-------|---------|
| Port_Bizerte | Producteur Ciment | 200t Ciment | 80t Verre |
| Zone_Sousse | Producteur Verre | 180t Verre | 100t Ciment |
| Pole_Sfax | Producteur mixte | 150t Ciment + 100t Verre | Rien |
| Hub_Tunis | Consommateur pur | Rien | 150t Ciment + 120t Verre |

## Équilibre
- **Ciment** : Offre=350t, Demande=250t → **Surplus 100t**
- **Verre** : Offre=280t, Demande=200t → **Surplus 80t**

## Coûts : 2 à 9 DT/tonne
